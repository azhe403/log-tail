log-tail: standing rule — always kill any running LogTail app instance (process name LogTail) before building or running tests, no questions asked. A running instance locks src/LogTail.UI/bin/Debug/net10.0/*.dll and fails dotnet build with MSB3027/MSB3021 copy errors (observed 2026-10-15: PID 23412 blocked the build; killing it made the build green). Just do it immediately instead of reporting the lock first.
